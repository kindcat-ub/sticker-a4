# Sticker/A4

[English](README.md)

Небольшой браузерный инструмент для размещения физических стикеров на листе A4 и печати текста на них в два прохода.

**Онлайн:** https://stickers.kindcat.dev

## Быстрый старт

1. Добавьте **Стикер 76**, **Стикер 90** или создайте свой тип стикера.
2. Разместите стикеры на виртуальном листе **A4 (210 × 297 мм)**.
3. Выберите стикер:
   - перетаскивайте сам стикер, чтобы менять его положение;
   - нажмите **замок**, когда позиция уже выставлена;
   - меняйте размер текстовой области за её маркеры;
   - тяните центральный маркер, чтобы двигать всю текстовую область целиком.
4. Дважды кликните внутри текстовой области, чтобы редактировать текст прямо на макете.
5. Включите **Автоподгонку**, если шрифт должен автоматически уменьшаться, чтобы текст помещался в заданную область.
6. Переключитесь в **GUIDES** и распечатайте направляющие.
7. Наклейте реальные стикеры поверх напечатанных контуров.
8. Переключитесь в **CONTENT**, снова вставьте тот же лист A4 в принтер и распечатайте текст.
9. Если второй проход смещён, используйте общую **X/Y-калибровку принтера**, а не двигайте каждый стикер вручную.

Редактор также поддерживает табуляцию, монохромные символы, привязку по миллиметровой сетке, пользовательские размеры стикеров, именованные макеты, импорт/экспорт JSON и интерфейс RU/EN.

## Печать

Чтобы физические размеры совпадали с макетом, в диалоге печати выставьте:

- Paper: **A4**
- Scale: **100%**
- Margins: **None**
- Headers and footers: **Off**

Рабочий цикл:

**GUIDES → наклеить стикеры → CONTENT**

## Горячие клавиши

- **Ctrl+Z** — отменить
- **Ctrl+Shift+Z** — повторить
- **Ctrl+D** — дублировать выбранный стикер
- **Delete** — удалить выбранный стикер
- **Ctrl+S** — сохранить именованный макет
- **Ctrl+P** — печать текущего прохода

## Макеты и хранение

Backend отсутствует. Макеты, типы стикеров и настройки хранятся в **localStorage** текущего браузера.

На другом ПК или в другом браузере будет отдельное локальное состояние. Для переноса используйте:

- **Export JSON** — резервная копия или перенос макетов;
- **Import JSON** — восстановление на другом устройстве.

## Локальный запуск

Сборка не требуется.

```bash
python3 -m http.server 8080 --directory public
```

После этого откройте:

```text
http://localhost:8080
```

## Cloudflare Workers

В репозитории уже есть `wrangler.jsonc`. Статическую версию можно развернуть командой:

```bash
npx wrangler deploy
```

Боевой адрес:

```text
stickers.kindcat.dev
```
